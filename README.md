# Приложение «Обувь» (Shoestore)

## Описание проекта

«Обувь» — десктопное приложение на Python с графическим интерфейсом PyQt5 и базой данных PostgreSQL для учёта товаров и заказов магазина обуви. Приложение позволяет просматривать каталог товаров, искать и фильтровать товары, а также оформлять и просматривать заказы в зависимости от роли пользователя.

## Возможности

- каталог товаров с поочерёдным просмотром карточек;
- отображение артикула, категории, наименования, описания, производителя, поставщика, единицы измерения и количества на складе;
- расчёт цены со скидкой и вывод старой цены зачёркнутой;
- подсветка товаров с большой скидкой и товаров, которых нет в наличии;
- вход по логину и паролю из таблицы `client`, а также вход гостем;
- разграничение прав по ролям: «Гость», «Авторизированный клиент», «Менеджер», «Администратор»;
- поиск по наименованию и описанию товара (менеджер, администратор);
- фильтрация по поставщику и сортировка по количеству (менеджер, администратор);
- добавление, редактирование и удаление товаров (администратор);
- выбор изображения товара при добавлении или редактировании;
- просмотр заказов с поочерёдным переходом между ними (менеджер, администратор);
- удаление заказов (администратор);
- создание заказов с выбором товара, пункта выдачи и статуса (администратор).

## Требования

- Python 3.10
- PostgreSQL
- PyQt5
- psycopg2-binary

Зависимости Python перечислены в файле `requirements.txt`.

## Установка

1. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   source venv/bin/activate
   ```

   В Windows активация выполняется командой `venv\Scripts\activate`.

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте базу данных PostgreSQL и примените скрипт `database/database.sql`:

   ```bash
   createdb magazin_obuv
   psql -d magazin_obuv -f database/database.sql
   ```

   Имя базы данных можно изменить, указав его в `config.ini`.

## Настройка подключения к БД

Параметры подключения хранятся в файле `config.ini` в секции `[database]` и читаются модулем `configparser` в `db_config.py`. Приложение получает из него словарь `DB_CONFIG`.

1. Скопируйте образец конфигурации:

   ```bash
   cp config.ini.example config.ini
   ```

2. Откройте `config.ini` и укажите реальные параметры подключения:

   ```ini
   [database]
   host=localhost
   port=5432
   database=magazin_obuv
   user=postgres
   password=your_password
   ```

`config.ini` содержит локальные настройки и **не должен попадать в Git**: файл добавлен в `.gitignore`. В репозитории хранится только `config.ini.example` с вымышленными значениями.

## Запуск

Запускайте приложение из корня репозитория, потому что пути к формам `ui/` и ресурсам `resources/` заданы относительно рабочей директории:

```bash
python main.py
```

## ER-диаграмма

Схема базы данных приведена в файле [`docs/ER-diagram.png`](docs/ER-diagram.png). Диаграмма построена по реальному скрипту [`database/database.sql`](database/database.sql).

В базе данных используются следующие таблицы:

- `client` — пользователи системы: роль, ФИО, логин (первичный ключ) и пароль;
- `tovar` — товары: артикул, наименование, категория, цена, количество, скидка и изображение;
- `pvz` — пункты выдачи заказов;
- `orders` — заказы: дата создания и доставки, пункт выдачи, клиент, код и статус;
- `order_tovar` — состав заказа (связующая таблица между `orders` и `tovar`), хранит количество единиц товара.

Связи между таблицами:

- `orders.order_pvz_id_fk` → `pvz.pvz_id` (многие к одному);
- `orders.order_client_name` → `client.user_login` (многие к одному);
- `order_tovar.order_id` → `orders.order_id` (многие к одному);
- `order_tovar.tovar_id` → `tovar.tovar_id` (многие к одному).

Первичные ключи обозначены на диаграмме как `PK`, внешние ключи — как `FK`.
